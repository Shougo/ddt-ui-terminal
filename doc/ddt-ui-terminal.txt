ACTIONS                                              *ddt-ui-terminal-actions*

                                                   *ddt-ui-terminal-action-cd*
cd
		params:
			{directory}: New current directory.

		Send a shell command to change the terminal process directory
		to {directory}.

		NOTE: This does not change Vim/Neovim's current directory.

                                          *ddt-ui-terminal-action-executeLine*
executeLine
		Execute the command line.

                                               *ddt-ui-terminal-action-insert*
insert
		params:
			{str}: Target string.

		Insert {str} to the process without it.

                                           *ddt-ui-terminal-action-nextPrompt*
nextPrompt
		Move to the next prompt from cursor.

                                          *ddt-ui-terminal-action-pastePrompt*
pastePrompt
		Paste the history to the command line.

                                       *ddt-ui-terminal-action-previousPrompt*
previousPrompt
		Move to the previous prompt from cursor.

                                               *ddt-ui-terminal-action-redraw*
redraw
		Redraw the UI.

                                                 *ddt-ui-terminal-action-send*
send
		params:
			{str}: Target string.

		Send {str} to the process and press <CR>.

                                       *ddt-ui-terminal-action-setCommandLine*
setCommandLine
		params:
			{str}: Target string.

		Send {str} to the terminal process without pressing <CR>.

PARAMS                                                *ddt-ui-terminal-params*

                                               *ddt-ui-terminal-param-command*
command		string[]
		Shell command and arguments to launch.

		Required to create a terminal buffer.
		An empty value causes an error.

		Default: []

                                                   *ddt-ui-terminal-param-cwd*
cwd		string
		The initial working directory of the terminal process.

		If empty, the current Vim/Neovim directory is used.

                                      *ddt-ui-terminal-param-extraTermOptions*
extraTermOptions Record<string, unknown>
		Additional options passed to the terminal API.

		In Neovim, these options are passed to |jobstart()|.
		In Vim, these options are passed to |term_start()|.

		Default: {}

                                      *ddt-ui-terminal-param-floatingBorder*
floatingBorder	string
		Set the border style of the floating window.

		This parameter is used when |ddt-ui-terminal-param-split|
		is "floating" in Neovim.

		Default: ""
                                         *ddt-ui-terminal-param-promptPattern*
		Sets the Vim script regular expression used to identify
		the shell prompt.

		NOTE: The right prompt is not supported.
		NOTE: If empty, prompt-related actions such as
		|ddt-ui-terminal-action-executeLine| and prompt navigation
		are unavailable.

		Default: ""
                                                 *ddt-ui-terminal-param-split*
split
		Specify the split direction.

		"":
			No split
		"floating":
			Use Neovim floating window feature
			NOTE: In Vim, "floating" falls back to a horizontal
			split.
		"vertical":
			Split buffer vertically
		"farleft":
			Split buffer far left, like |CTRL-W_H|
		"farright":
			Split buffer far right, like |CTRL-W_L|
		otherwise:
			Split buffer horizontally

		Default: ""

                                           *ddt-ui-terminal-param-startInsert*
startInsert	boolean
		Start insert mode in Neovim.
		NOTE: In Vim, a newly created terminal buffer is always started
		in insert mode.

		Default: v:false

                                                *ddt-ui-terminal-param-winCol*
winCol		number
		Set the 0-based column of the floating window.

		Default: 50

                                             *ddt-ui-terminal-param-winHeight*
winHeight	number
		Set the height of the window if |ddt-ui-terminal-param-split|
		is "horizontal".

		Default: 15

                                                *ddt-ui-terminal-param-winRow*
winRow		number
		Set the 0-based row of the floating window.

		Default: 20

                                              *ddt-ui-terminal-param-winWidth*
winWidth	number
		Set the width of the window if |ddt-ui-terminal-param-split|
		is "vertical".
		If |ddt-ui-terminal-param-split| is "floating", set the width
		of the floating window.

		Default: 80

EXAMPLES                                            *ddt-ui-terminal-examples*
>vim
	call ddt#custom#patch_global(#{
	      \   ui: 'terminal',
	      \   uiParams: #{
	      \     terminal: #{
	      \       command: ['zsh'],
	      \       promptPattern: has('win32') ? '\f\+>' : '\w*% \?',
	      \     },
	      \   },
	      \ })

	nnoremap <buffer> <C-n>
	      \ <Cmd>call ddt#ui#do_action('nextPrompt')<CR>
	nnoremap <buffer> <C-p>
	      \ <Cmd>call ddt#ui#do_action('previousPrompt')<CR>
	nnoremap <buffer> <C-y>
	      \ <Cmd>call ddt#ui#do_action('pastePrompt')<CR>
	nnoremap <buffer> <CR>
	      \ <Cmd>call ddt#ui#do_action('executeLine')<CR>
	
	augroup ddt-ui-terminal
	  autocmd!
	  autocmd DirChanged <buffer>
	        \ call ddt#ui#do_action('cd', #{
	        \   directory: v:event->get('cwd', getcwd()),
	        \ })
	augroup END
<
